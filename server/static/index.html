AETHER.ID System Architecture

HH Goa 2026
01

Multi-Representation Search

Queries reverse search engines using both Representation A (Full Scene Context) and Representation B (Padded Face Crop +20%).

02

Provider Cascade

Cascades from primary Google AI Studio Gemini Search (Grounding) to SerpApi Google Lens and TinEye reverse search engines.

03

Biometric Match Authority

FaceNet / InceptionResnetV1 (512-d L2 vector) serves as the sole biometric identity decision maker (Cosine Sim $\ge 0.60$, Margin $\ge 0.05$).

04

Two-Tier Canonical Data

Tier A (Immutable URL, Platform, Text, Image SHA-256) is hashed into contentHash. Tier B (Audit timestamps/latency) remains off-chain.

05

Sequential Record ID

Solidity contract keys records by sequential recordId, allowing verification to distinguish TAMPER DETECTED from RECORD_NOT_FOUND.
